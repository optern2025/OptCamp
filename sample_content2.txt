QUESTION 2
Type: debug
Prompt:
A React component is re-rendering infinitely. Identify the cause and fix it.
Guidance:
Look at the useEffect dependency array and state updates.
Rubric:
Candidate should identify the circular dependency between the state update and the effect.
Solution:
The useEffect updates a state variable that is also in its dependency array, so React keeps rerunning the effect; add a dependency array like `[userId]` and move any state updates inside callbacks that depend on those values.
Language: typescript
Starter Code:
```tsx
function UserProfile({ userId }) {
const [user, setUser] = useState(null);

useEffect(() => {
fetchUser(userId).then(u => setUser(u));
}, [userId]); // <--- Missing dependency array!

if (!user) return <div>Loading...</div>;
return <div>{user.name}</div>;
}
```
Expected Outcome:
Candidate adds the missing dependency array `[userId]` to the useEffect hook and avoids updating state in a way that retriggers the effect unnecessarily.
END QUESTION
